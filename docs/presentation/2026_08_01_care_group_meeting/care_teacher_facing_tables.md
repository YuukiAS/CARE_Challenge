# CARE 组会展示表

这份是给老师现场看的表。它只回答三件事：现在谁最稳、哪些新结果真的有用、为什么还不能说已经完成。下面把 nnU-Net 叫作“朴素基线”，MoSAIC 叫作“外部模型”，M0R 叫作“最新复放模型”；完整证据链只放在后台台账，不拿来逐行投屏。

## 1. 先给老师看的总表

| 老师最可能问的问题 | 可以直接回答的话 | 边界 |
|---|---|---|
| 现在本地最稳的是谁？ | 还是朴素基线。它在本地公平留出评估里，瘢痕分割重叠分数 0.5610，水肿 0.4308。 | 不能拿 12 个样本上的挑选分数 0.922x，说它在正式留出或官方验证上也有 0.92。 |
| 外部模型是不是比朴素基线强？ | 不能这样笼统说。外部模型在官方隐藏榜的瘢痕分数高，达到 0.6965；但在本地公平留出评估里，瘢痕只有 0.3782，水肿只有 0.0528。 | 可以说“官方隐藏榜瘢痕有优势”，不能说“这个架构在本地公平比较里全面更强”。 |
| 最新这轮模型有没有成？ | 只成了一半。最新复放模型在目标域复放集里，瘢痕到 0.6500，比本地基线更有希望；水肿只有 0.4340，基本还停在基线附近。 | 不能说完整目标域模型已经准备好，也不能上传验证集或宣称官方成绩。 |
| 为什么前面很多路线没有变成结果？ | 主要不是因为没跑，而是因为最终输出没有真的被改好：有的模块不影响最终分割，有的会带来远处假阳性，有的让体积失控，有的只在挑选集好看。 | 不能把“验证脚本通过”“小样本冒烟通过”“作业已提交”当成模型有效。 |
| 组会后最该做什么？ | 瘢痕线可以继续沿最新复放模型查；水肿要单独修，重点看 CenterC 漏检、小病灶定位、T2 边界和远离心肌的假阳性。 | 不能让“优先保瘢痕”的策略代替水肿专门机制。 |

## 2. 数字放在一起时怎么解释

| 证据来源 | 看到的数字 | 这组数字说明什么 | 不能拿它说明什么 |
|---|---|---|---|
| 官方隐藏榜历史记录 | 朴素基线：瘢痕约 0.5969，水肿约 0.6496；外部模型归因行：瘢痕 0.6965，水肿 0.6255。 | 说明外部隐藏验证里，外部模型的瘢痕结果曾经更高。 | 不能证明本地公平评估里外部模型全面更强，因为官方隐藏榜没有本地逐例真值可复核。 |
| 本地公平留出评估 | 朴素基线：瘢痕 0.5610，水肿 0.4308；外部模型：瘢痕 0.3782，水肿 0.0528。 | 这是本地最公平的同人群比较。按这个口径，朴素基线明显更稳。 | 不能和官方隐藏榜、挑选集、目标域复放集直接混比。 |
| 最新模型的小样本选择集 | 最新复放模型：瘢痕 0.8883，水肿 0.7920。 | 只说明这一轮挑选源模型时，最新复放模型最值得继续检查。 | 不能当最终泛化成绩。 |
| 最新模型的目标域复放集 | 最新复放模型：瘢痕 0.6500，水肿 0.4340。 | 这是这轮最该汇报的本地结论：瘢痕有进展，水肿没有真正过关。 | 不能说“全任务准备好”，也不能代替官方验证。 |

## 3. 失败路线只讲原因，不堆名词

| 过去尝试 | 老师需要听到的失败原因 | 还能保留下来的价值 |
|---|---|---|
| 早期的分割修复路线 | 看起来加了修复模块，但最后输出几乎没变；等于没有真正改到最终分割。 | 留下了“必须检查最终输出变化”的审计方法。 |
| 后期的分割修复路线 | 终于能改变最终输出，但瘢痕略受伤，水肿改善不稳定，还会引入远处假阳性。 | 留下了逐例判断“帮了谁、伤了谁”的分析表。 |
| 多模态直接训练 | 同人群下明显低于朴素基线：瘢痕 0.2903，水肿 0.2431。 | 留下了模态缺失和标签清洗的经验。 |
| 多模态蒸馏 | 结果很差：瘢痕 0.0831，水肿 0.0803，并且体积和远处假阳性失控。 | 说明蒸馏不能直接照搬，必须先约束输出空间。 |
| 级联修正 | 最好的提升也只有千分级别，实际修正能力太弱。 | 留下了教师缓存、覆盖范围和安全边界检查。 |
| 域泛化尝试 | 没形成可以和本地公平留出评估直接对比的主结果。 | 留下了按中心、模态和 T2 缺失分层看的框架。 |
| 结构先验路线 | 几何约束本身不够可靠，没到可以训练四臂模型的程度。 | 留下了输入契约和几何可用性检查。 |
| 病理检索级联 | 第 0 折外层测试低于朴素基线：瘢痕 0.4196 对 0.5341，水肿区 0.2472 对 0.5592。 | 留下了检索加软级联为什么不稳的反例。 |

## 4. 展示病例只选能讲清楚问题的

|---|---|---|---|

| Case3009 | CenterC 水肿仍弱。 | 水肿 0.3173；瘢痕 0.6840。 | 瘢痕能看，但水肿召回和边界还不稳。 |

## 5. 组会投屏顺序

| 顺序 | 放哪张表 | 讲法 |
|---|---|---|
| 1 | 先放总表。 | 30 秒讲清楚：本地最稳还是朴素基线；外部模型只在官方隐藏榜瘢痕上更亮；最新模型只够说瘢痕有希望。 |
| 2 | 再放数字解释表。 | 把官方隐藏榜、本地公平留出、小样本选择、目标域复放分开，先堵住“为什么数字不能直接比”的问题。 |
| 3 | 然后放 4 个病例。 | 用 Case3008、Case3027、Case2012、Case2021 讲水肿漏检、误报、位置错和不能伤好病例。 |
| 4 | 最后放失败路线表。 | 回答“为什么前面没成”，并说明这些失败留下了哪些检查规则。 |
