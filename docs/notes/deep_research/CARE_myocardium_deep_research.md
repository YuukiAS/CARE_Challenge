# CARE-Myocardium 心肌病灶分割挑战深度调研与基线搭建路线

## 挑战任务与现实难点
该挑战的核心目标是从心脏磁共振（CMR）序列中分割心肌病灶区域，重点包括**瘢痕（scar）**与**水肿（edema）**两类病理。挑战被设计为两条子任务：**MyoPS**（利用多序列MS-CMR进行scar+edema分割）与**CineMyoPS**（只用cine CMR分割scar）。挑战强调真实世界困难：**多中心数据差异**、**部分中心缺失序列**、以及**多序列间空间不对齐/错位**。

从任务定义看，MyoPS输入包含 LGE、T2 与 bSSFP（cine）等序列：scar主要在 LGE 上评估/标注，edema主要在 T2 上评估/标注；CineMyoPS 仅使用 cine 序列，并在**舒张末期（end-diastolic, ED）帧**上评估 scar。

标签体系方面，挑战给出了固定的“像素值编码”（而非常见的连续类别ID），包括：Scar=2221、Edema=1220、LV=500、Myocardium=200、RV=600。建模时通常需要在训练阶段把它们映射到 \(\{0,1,2,\dots\}\) 的内部类别索引，在导出结果时再映射回指定的标签值。

评测指标在挑战说明中明确包含 **Dice** 与 **Hausdorff Distance（HD, mm）**（官网页面版本还额外列出了Precision/Sensitivity；你的PDF版本只写了Dice+HD，建议训练/验证时两套都统计，但以官方评测脚本为准）。
在医学分割评估中，Dice 系数常写为
\[
\mathrm{DSC}(P,G)= \frac{2|P\cap G|}{|P|+|G|}
\]
而 HD 用于衡量边界集合之间的最大最近距离（对离群点较敏感，常与Dice互补）。

规则上，挑战只接受**全自动方法**；同时允许使用预训练基础模型（示例包括 SAM、CLIP、MedSAM），这为“基础模型特征/蒸馏/伪标签”等路线打开了空间，但也要求你把“提示（prompt）”过程做成可自动生成的算法模块，而不是人工交互。

## 四篇起点文献的关键思想与可迁移模块
这四篇文献几乎是“为该挑战量身定制”的方法谱系：从**概率模型的联合配准-分割**，到**多序列灵活融合**，再到**对齐驱动的端到端框架**与**cine-only 的运动+解剖+病灶联合建模**。

首先，2019年在 *IEEE Transactions on Pattern Analysis and Machine Intelligence*（TPAMI）发表的 MvMM 工作，把多源/多序列分割表述为“纹理分类 + 联合强度分布建模”，并把**跨序列配准（含切片级错位）**嵌入到最大似然框架里，在一个“虚拟公共空间”里同时优化配准与分割参数，强调对**序列间不对齐**与**不完整覆盖（incongruent data）**的鲁棒性。对挑战而言，它提供了一条重要范式：**不要把配准当作纯预处理；把对齐当作与分割共优化的变量**。

其次，MyoPS-Net（MedIA 2023）明确面向“临床序列组合不完整”场景，提出能够应对“不同数量、不同组合模态”的端到端网络，并显式引入**解剖知识约束**（例如强调心肌一致性、利用心肌定位病灶）与**病灶关系约束**（文中以“inclusiveness loss”等方式利用 scar 与 edema 的空间/集合关系）。这直接对应挑战的两个痛点：**缺序列**与**病灶必须位于心肌内部的先验**。

再次，Aligning multi-sequence CMR（TMI 2023）把挑战里最关键的现实问题——**MS-CMR在临床上常不对齐**——放在方法核心，提出 U-MyoPS：用深度网络估计 TPS 变换，把 bSSFP/T2/LGE 配准到共同参考空间；然后在共同空间提取心肌结构，作为空间先验（SPG gate）去约束病灶分割，形成“配准—解剖—病灶”的统一框架。它的工程启示非常直接：如果数据确实存在错位，与其盲目做多模态特征拼接，不如先明确一个“共同空间”并在特征层做可微对齐与融合。

最后，CineMyoPS（TMI 2025）给 cine-only 子任务提供了相对完整的结构化解法：用 U-shaped 的配准子网络预测从每帧到 ED 参考帧的稠密位移场（DDF），抽取“运动特征”；再用解剖分割网络预测结构，并通过一致性损失把“只标注ED帧”的监督扩展到全心动周期；最后融合**运动 + 解剖 + 纹理（原始cine强度）**进行病灶分割，并把预测统一到 ED 参考空间。这套设计解释了为什么 cine-only 仍可能分割出 scar：cine 的价值更多来自**运动异常与几何重塑**而非 LGE/T2 的直接组织对比。

补充背景上，MyoPS Challenge 的基准分析论文把参赛方法归纳为预处理、增强、学习策略、结构设计、后处理等维度，并说明早期公开数据为了降低难度曾使用“三序列预对齐”；而你这个挑战反而把“真实世界错位/缺序列”放回来了，因此对齐与缺模态鲁棒性会比早期 MyoPS2020 更关键。

## Baseline 选择：为什么使用 nnU-Net 而不是 MyoPS-Net / CineMyoPS

### 一、核心结论

在 CARE Myocardium 挑战赛中，baseline 应优先选择 **nnU-Net**，而不是直接复现已有方法（如 MyoPS-Net 或 CineMyoPS）。

原因不是这些方法效果不好，而是：

> **baseline 的目标是“稳定、可复现、可对比”，而不是直接追求 SOTA。**

### 二、任务背景决定 baseline 需要“稳”

根据 challenge 描述，任务的核心难点包括：

- 多中心数据（domain shift）
- 多序列组合不一致（missing modality）
- 多序列空间不对齐（misalignment）

因此 baseline 必须具备：

- 鲁棒性（robustness）
- 可泛化性（generalization）
- 可扩展性（方便后续改进）

### 三、为什么不直接用 MyoPS-Net / CineMyoPS？

#### 1. 论文方法依赖特定假设，泛化性有限

**MyoPS-Net（2023）**

- 针对 multi-sequence 设计
- 内置 modality fusion 和 missing handling
- 强依赖特定数据分布

问题：

- challenge 中不同 center 的数据分布差异较大
- 序列组合不统一（有的只有 LGE，有的有 3 个序列）
- 原论文假设可能不成立

**CineMyoPS（2025）**

- 专门针对 cine-only
- 依赖 multi-sequence teacher model 进行知识迁移

问题：

- 缺乏完整 pretraining pipeline
- teacher model 不可用
- 复现难度高，稳定性差

#### 2. 论文方法通常难以复现

常见问题：

- 代码不完整或不可用
- 训练细节缺失（loss / schedule / augmentation）
- 参数高度依赖作者经验

结果：

- 训练不稳定
- 性能难以达到论文水平
- 调试成本极高

#### 3. 不适合作为“对照 baseline”

baseline 的作用是：

> 提供一个“干净、可控”的参考点，用于评估改进方法

如果 baseline 已经是复杂模型（如 MyoPS-Net）：

- 已包含 fusion、missing handling 等机制
- 后续改进难以解释来源
- ablation 不清晰

### 四、为什么 nnU-Net 是标准 baseline？

#### 1. 自动适配数据（非常关键）

nnU-Net 自动处理：

- spacing / resampling
- patch size
- batch size
- normalization

特别适合 multi-center heterogeneity。

#### 2. 强鲁棒性

nnU-Net 默认配置：

- instance normalization
- heavy data augmentation
- class-balanced loss

对小样本 + 多中心数据表现稳定。

#### 3. 符合 challenge 设计逻辑

challenge 允许使用：

- pre-trained models（SAM / CLIP / MedSAM）

说明：

> 官方默认你使用标准 pipeline + 再进行改进

而不是复现特定论文方法。

#### 4. 社区共识（重要）

在 MICCAI / 医学影像竞赛中：

> **nnU-Net ≈ 默认 baseline**

原因：

- 可复现
- 稳定
- reviewer 认可

### 五、正确理解：baseline vs 方法

不要理解为：

- nnU-Net 比 MyoPS-Net 更先进 ❌
- nnU-Net 性能更好 ❌

而应该理解为：

- nnU-Net = **零假设模型（neutral baseline）**
- MyoPS-Net = **带强结构假设的模型（biased model）**

### 六、推荐策略（实际落地）

#### Step 1：Baseline

使用 nnU-Net：

- 输入：多序列（LGE / T2 / bSSFP）
- 简单处理 missing modality（zero + mask）
- 不引入复杂结构

#### Step 2：引入已有方法思想

将论文方法“拆解为模块”，而不是直接复现：

- MyoPS-Net → modality dropout
- U-MyoPS（TMI 2023，对齐多序列 CMR）→ feature-level alignment
- CineMyoPS → teacher-student distillation

#### Step 3：构建最终模型

组合：

- nnU-Net backbone
- + modality robustness
- + domain generalization
- + structure constraint

形成自己的方法体系。

### 七、直观类比（帮助理解）

可以类比 CV：

- nnU-Net ≈ ResNet（标准 backbone）
- MyoPS-Net ≈ 某篇 CVPR 特定模型

你不会：

- 用某篇 CVPR 模型作为 baseline

而是：

- 用 ResNet + 自己加模块

### 八、总结一句话

> baseline 使用 nnU-Net，是为了控制变量、保证稳定性，并为后续方法改进提供清晰参考点；  
> MyoPS-Net 和 CineMyoPS 应作为“思想来源”，而不是直接作为 baseline。

## Baseline 如何搭建才“像一个能打的挑战基线”
下面给出一个**可落地**且能覆盖挑战三大难点（多中心差异、缺序列、错位）的 baseline 方案。其核心思想是：先用医学分割领域验证过的强范式（nnU-Net类训练配方），再在两处“定制”：**缺序列融合**与**对齐/空间先验**。

### 数据与预处理基线
推荐把 MyoPS 与 CineMyoPS 视作**共享解剖分割骨干 + 任务特定病灶头**的多任务问题，并以“病例”为单位组织样本，以便正确处理缺序列与中心域差异。挑战数据确实存在中心级别的序列缺失（例如部分中心只有LGE，部分中心只有LGE+bSSFP等），因此数据加载器应支持“模态集合可变”。

强烈建议采用 *Nature Methods* 上被广泛认可的 nnU-Net 思路作为训练配方基底：包括自动/半自动的重采样、强数据增强、patch-based训练、深监督、测试滑窗等——它在医学分割里长期作为强基线的原因是“把工程细节系统化并对新任务自配置”。
在此之上，你需要两类关键预处理：

一类是**强度归一化与跨中心风格差异**。MRI跨中心差异（扫描仪、协议、重建）常导致强度分布变化，单纯z-score未必足够；可在增强中加入“直方图匹配/风格扰动”来构造域多样性。直方图匹配作为心脏分割跨域增强在多中心/多vendor任务中已有实证收益，并且实现成本低。
（实践层面：把“HM增强”当作一种随机增强操作，对每个patch以一定概率匹配到来自另一中心样本的直方图，或匹配到一个滑动维护的“风格库”。）

另一类是**跨序列对齐**。如果你选择“先配准再分割”的管线，建议把 bSSFP(cine ED) 或 LGE 设为参考，使用全自动刚体+非刚体配准（例如传统ANTS/Elastix或学习式VoxelMorph类模块）。若你更希望端到端，则可以直接参考 U-MyoPS：预测 TPS/DDF 并在特征层对齐后再融合。学习式配准如 VoxelMorph 的优势是推理快、可与分割网络共享训练策略；而其基本思想（学习从图像对到形变场的映射）已有成熟公开实现与大量引用。

### 模型结构基线
一个“够强且可复现”的结构建议如下：

**主干：3D U-Net / nnU-Net 3D fullres（或2.5D）**
心肌与病灶（尤其scar）往往在短轴方向呈现细薄结构，3D上下文通常有帮助，但具体取决于体素间距与切片厚度；若各中心切片厚度差异大，可退一步采用 2.5D（堆叠相邻切片）来兼顾鲁棒性与计算成本。nnU-Net的可配置性正好适配这种不确定性。

**输入：多模态可变集合 + 模态mask**
最直接的做法是把 LGE/T2/bSSFP 当作通道拼接，但这在“缺通道”时会出问题。更稳健的基线是“模态专属encoder + 融合器”的结构：每个模态一个浅层编码器（共享或不共享参数都可），得到模态特征后，用一个对缺模态鲁棒的聚合方式融合。经典的缺模态分割框架 HeMIS 给出了一个非常简单但有效的聚合思想：把每个模态映射到潜空间后做可交换的统计聚合（如均值/方差），天然支持任意模态子集输入。你可以把 HeMIS 的“统计聚合”替换为更强的注意力/门控，但基线阶段建议先实现 HeMIS-like，以确保缺序列不崩。

**输出：解剖与病灶多头**
建议至少输出 \(\{\text{LV}, \text{Myo}, \text{RV}\}\) 解剖结构与 \(\{\text{Scar}, \text{Edema}\}\) 病灶（哪怕评测只看scar/edema，解剖头也能提供强先验）。这与 MyoPS-Net 的“解剖一致性/定位病灶”的思路一致，也与 U-MyoPS 的“先提取心肌，再做病灶”一致。

**空间先验：心肌mask gating / loss约束**
把“病灶必须在心肌内”变成网络结构或损失的一部分：例如在病灶头前对特征乘以心肌概率图（soft gating），或在损失中对“病灶落在心肌外”的区域加罚。MyoPS-Net使用“inclusiveness”等关系约束，U-MyoPS用SPG传播心肌信息，本质都在强化这一几何先验。

### 训练目标与损失基线
该任务的最难点之一是 scar/edema 属于**小目标、强类别不平衡**。只用 Dice+CE 往往能跑，但HD未必好。建议基线阶段采用“区域重叠 + 小目标友好 + 边界友好”的组合：

- 基础：\(\mathcal{L}_{seg}=\mathcal{L}_{Dice}+\mathcal{L}_{CE}\)（多类或多头加权求和）——这是医学分割常用组合。
- 小目标增强：Tversky / Focal-Tversky 系列用于改善不平衡与召回-精度权衡，特别适合病灶这种稀疏结构。
- HD导向：如果挑战真的以HD作为关键指标之一（你的PDF版本确实写了HD），建议至少在P1阶段加入“减HD的可微损失”或边界损失，因为纯Dice高但HD差在小病灶上很常见。已有工作展示了通过专门的损失设计可以显著降低HD而不牺牲Dice。

此外，你必须面对“**部分样本缺少某些类别的标注**”：例如只有LGE的中心不可能有T2-edema监督，甚至有的中心只标scar。你需要在loss里引入“类别可用性mask”（只对存在标注的头/类别回传梯度），否则会把“未标注当作背景”导致系统性偏差。这一点在多中心真实数据中极常见，也是 MyoPS-Net 强调“临床缺序列/复杂组合”的现实原因之一。

### 推理与后处理基线
推理建议采用 nnU-Net 风格：滑窗 + 重叠融合，必要时做轻量TTA（翻转）与fold ensemble。nnU-Net与MyoPS基准分析都强调“后处理/集成”对小结构指标的影响不可忽视。

在病灶后处理上，优先做**规则化而非复杂启发式**：
- 把 scar/edema 预测强制裁剪在 myocardium 内（用软心肌概率阈值或形态学膨胀后的心肌mask），这是低风险、通常能显著减少假阳性并改善HD。其合理性来自挑战任务本身的解剖约束，以及多篇起点论文把心肌作为空间先验的做法。
- 对极小离散连通域做体积阈值过滤（阈值可按体素体积设定，并在验证集上调参），以抑制噪声对HD的“极端放大”效应（HD对离群点敏感）。

### CineMyoPS 的“最低可用基线”
只用ED帧做2D/3D分割可以作为最小基线，但往往上限较低，因为 cine 的病灶信息更多来自心动周期的运动异常与形态改变。CineMyoPS 论文提供了一个可复用的强结构：以 ED 为参考，用配准子网络估计各帧到ED的DDF并聚合运动/解剖/纹理特征，同时用一致性损失把“只标ED解剖”的监督扩展到全序列。即使你不实现完整三模块，也建议至少做“全帧输入 + 显式/隐式运动聚合”。
在更广的影像学研究中，也已有工作验证非增强cine MRI可用于慢性心梗的检测/定位/勾画，这从侧面支持“cine-only分割”并非纯玄学，但需要更强的时序表征。

## 近三年医学影像与通用CV的关键进展对本挑战意味着什么
医学分割近三年的主线变化可以概括为三类：**Transformer化**、**基础模型化**、以及**更系统的跨域/鲁棒性策略**。这些趋势与本挑战的三大难点有非常直接的映射关系。

在结构上，Transformer/混合架构在医学3D分割中已经形成稳定范式。例如 UNETR 用 Transformer 作为编码器来捕获长程依赖，Swin UNETR 则把层级Swin Transformer引入3D分割，并配合自监督预训练进一步提升可迁移性。对心肌病灶分割而言，Transformer的潜在价值主要在于：**跨切片/跨视野上下文**与**跨模态特征对齐**（尤其在多序列输入时），但代价是工程复杂与数据规模敏感。

在基础模型上，通用CV领域 Meta 提出的 SAM 把“可提示分割”扩展到大规模数据训练，形成“分割基础模型”的范式；医学影像侧则出现了 MedSAM 等“面向医学域的基础分割模型”，目标是弥合自然图像与医学图像域差。大量研究指出：直接把自然图像SAM零样本用于医学图像往往不够好，原因是域差；因此出现了 SAM-Med2D、Med-SA等适配/微调/Adapter路线，以及MedSAM这种在医学数据上系统训练的版本。对本挑战而言，关键不在于“拿SAM直接分割scar”，而在于两点：
- 用基础模型作**强表征初始化/特征提取器**，降低小数据训练不稳定。
- 用基础模型作**伪标签教师**或“边界细化器”，但必须把prompt自动化（例如由你的网络先预测粗mask/框，再喂给MedSAM细化），以满足“全自动”规则。

在鲁棒性上，医学影像的域泛化/域适应研究明显升温，尤其针对多中心、多设备差异：
- 数据层的直方图匹配增强在心脏结构分割跨域中被提出为简单有效的手段；
- 特征层“风格混合”如 MixStyle 通过混合特征统计生成隐式新域，常被作为轻量DG模块；
- 测试时自适应（TTA）如 TENT 通过最小化预测熵在线更新归一化参数，适合“源数据不可用/未知目标域”的场景；这对挑战的 OOD center 提升尤其有吸引力，但需要严格防止“测试时过拟合”。

对 CineMyoPS 子任务，还有一条“从cine生成LGE等价信息”的跨模态路线在临床研究中出现（例如 cine-generated enhancement 思路），从挑战角度看可以被理解为“先把cine翻译到更有病灶对比的空间，再做分割”；但这类方法的验证成本高、泛化风险大，更适合作为中后期探索方向。

## 提升方向与优先级路线图
下面把可能的扩展按“预期收益/实现成本/风险”综合排序（优先级越高越建议先做）。其中 P0 是你应当能在较短时间内复现的 baseline；P1/P2 更像“冲榜层”的系统增强；P3/P4 属于更激进、可能带来跃迁但也更不确定的路线。

### P0 强基线必须完成的部分
P0 的目标不是“最创新”，而是把挑战最常见的工程坑一次填平。

P0-1：nnU-Net级别训练配方 + 3D/2.5D U-Net 主干
把重采样、patch策略、增强、深监督、滑窗推理与基础loss走通，建立可复现实验框架。

P0-2：缺序列输入支持（模态mask + modality dropout）
即使你不做HeMIS聚合，也要确保：训练时随机丢模态（模拟缺序列），推理时缺序列不会崩。HeMIS提供了“任意模态子集可输入”的结构性解决方案，可作为P0或P1早期就引入。

P0-3：解剖-病灶多任务 + 病灶在心肌内约束
至少要有心肌mask分支，并在推理时裁剪病灶到心肌内；这是低风险高收益，且与起点论文的核心先验一致。

### P1 最值得优先投入的鲁棒性增强
P1 更贴近挑战真实难点，投入产出比通常很高。

P1-1：特征层缺模态聚合（HeMIS→门控注意力）
从“统计聚合（均值/方差）”升级为“带模态mask的注意力/门控融合”：例如把每个模态特征当作token，做跨模态注意力并用mask屏蔽缺模态。这在保持缺模态鲁棒性的同时，通常比简单拼接更能利用互补信息。HeMIS作为理论起点非常合适。

P1-2：显式对齐模块（传统配准或学习式配准）
如果验证集里能观察到明显序列错位，对齐几乎一定带来收益。两条实现路径：
- 纯自动传统配准（快速上线、解释性强）；
- 学习式配准（如VoxelMorph）或参考U-MyoPS的TPS对齐并在特征层融合。
U-MyoPS在该问题上的贡献是把“对齐+融合+空间先验”统一起来，特别契合挑战设定。

P1-3：针对HD优化的损失组合
如果你发现“Dice还行但HD很差”，建议在P1就引入边界/表面类损失或可微HD损失（例如Karimi等的HD相关损失、boundary loss）。它们在小结构分割上往往比继续调增强更直接。

P1-4：跨中心风格增强与轻量DG模块
把直方图匹配增强加入训练（简洁有效），再进一步可加 MixStyle 这类几乎“即插即用”的特征统计混合。

### P2 面向冲榜的系统性提升
P2 的特点是：每一项未必“单点巨大提升”，但组合后通常能稳定抬高上限。

P2-1：中心分层的交叉验证与集成
挑战本质是多域问题，推荐按“中心”做更严格的划分与验证（例如留一中心/多中心OOD验证），再做fold ensemble；MyoPS基准分析也把“训练策略与后处理”作为决定性因素之一。

P2-2：两阶段/级联细化（先结构后病灶）
小病灶常受限于ROI定位与分辨率：可以先做结构分割/粗ROI，再在ROI内高分辨率分割scar/edema。类似的“级联细化”在多序列心肌病灶分割中已有公开方法（例如MS-CaRe-CNN两阶段区分解剖与组织活性）。

P2-3：CineMyoPS的时序建模升级
对 cine-only，真正有效的提升通常来自利用多帧：最稳健的路线是复刻/简化 CineMyoPS 的“ED参考 + DDF对齐 + 一致性正则 + 多特征融合”。如果资源有限，也可先做“全帧堆叠到3D (x,y,t) U-Net”作为中间版本，再逐步替换为显式运动估计。

### P3 基础模型与大模型引入的可行打法
P3 并不等于“直接把SAM端到端拿来跑”，更像“把基础模型当作组件/教师/表征源”。

P3-1：MedSAM作教师的伪标签与边界细化
思路是：你的网络产生粗分割（或框/点），自动生成prompt喂给MedSAM做细化；再用细化结果做：
- 训练期的伪标签蒸馏（teacher-student）；
- 推理期的可选后处理“细化器”。
这完全可以做成全自动流程，并且挑战规则明确允许使用此类预训练基础模型（示例含MedSAM）。

P3-2：基础模型特征初始化/冻结编码器
在小数据或强域移位下，固定/半固定一个预训练编码器（医学域更优）并只训练轻量解码头，有时比从头训练更稳。SAM在医学域零样本不理想的证据促使大量工作采用Adapter/参数高效微调；这些经验同样可以迁移到你的编码器设计中。

P3-3：测试时自适应（TTA）用于未知中心
如果榜单存在明显OOD中心，TENT类TTA可作为推理阶段“最后一公里”。但需严格控制更新参数范围（通常只更新归一化层）并在验证集模拟，以防止不稳定。

P4-2：更强的联合配准-分割概率框架
从 MvMM 到 U-MyoPS 再到更通用的 groupwise/deep combined computing（如\(\mathcal{X}\)-Metric）可以看成一条“统计依赖建模→联合优化”的路线。若你想在对齐上做更系统的突破，可以把多序列/多帧统一成 N 输入的组配准问题，但工程复杂度显著上升。

## 建议的消融与评估组织方式
为了让改进“可解释且可复现”，建议把实验围绕挑战三大难点组织，而不是只做无差别调参。

围绕“缺序列”，至少做三组缺失模式：只LGE、LGE+bSSFP、LGE+T2+bSSFP（全模态），并在训练中用 modality dropout 模拟；这与 MyoPS-Net 对“复杂模态组合”的评估逻辑一致。

围绕“错位”，建议做：无配准拼接 vs 传统全自动配准 vs 学习式/端到端对齐（TPS/DDF），并比较在scar/edema上 Dice 与 HD 的变化；U-MyoPS 的方法论本质就是“对齐与融合不可分”。

围绕“多中心域移位”，建议用“按中心划分”的验证设置评估DG/TTA：
- 风格增强（直方图匹配）是否提升OOD；
- MixStyle是否带来稳定增益；
- TENT类TTA是否在某些中心有效、是否引入不稳定。

最后，务必把“后处理（心肌内裁剪、连通域过滤）”作为一个独立消融项记录，因为它对HD的影响可能比很多网络结构改动更大；这也符合医学分割评估对距离指标敏感性的常识与分析。
