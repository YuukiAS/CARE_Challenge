# CARE Final Output Readability Policy

本文件是 CARE 面向用户、Planner 或科研负责人的最终分析输出硬门槛。分析过程中可以使用仓库内部语言，但发送最终回答、结果解释、复盘、下一步建议或 planner prompt 前，必须先把机器语言重写成科研负责人能直接读懂的自然中文。

## Scope

本规则约束 human-facing final output，包括 GPT/Codex 最终回答、Batch 复盘、结果解释、下一步建议、`controller_report.md` 面向 Planner 的结论段、显式 reviewer 结论段和新 staged prompt 的分析性正文。Controller report 不是例外：它可以在末尾保留机器字段，但开头必须先说人话。

本规则不改变必须机器精确匹配的 YAML 字段、路径、命令、状态枚举、代码标识符、schema key、validator token 和 evidence 索引。内部标识可以保留，但只能用于定位，不能替代科学判断。

## Hard Requirements

1. 开头必须先用一个完整自然段给出结论。该段说明当前最重要的问题、为什么会出现、现在应当做什么、暂时不应当做什么。首段不得出现公式、文件路径、命令、全大写实验代号、下划线状态名或连续英文术语。
2. 内部实验名称不能代替科学判断。必须先用自然中文说明实际含义，之后才可在括号中给出仓库标签用于定位。例如先写“训练目标没有直接约束最终预测结果”，再补充内部标签。
3. 每段先解释意义，再给证据。不得以 loss 名称、指标数字、代码字段或文件路径作为段落开头。应先说明该证据回答了什么问题，再给 Dice、HD95、病例级改善或损害、baseline 对比和代码证据。
4. 复杂机制必须依次说明：当前机制原本想解决什么问题；现有实现为什么没有达到目的；建议改动具体改变哪条信息流或梯度路径；如何通过最小实验判断改动是否有效。
5. 公式前必须先用自然语言解释为什么需要该公式。公式后必须解释关键变量的含义，以及公式对模型行为产生的实际影响。每个公式只保留一份正确的 LaTeX，不得同时输出损坏的纯文本重复版本。
6. 训练阶段不能写成裸 checklist。每个阶段必须同时说明：该阶段试图排除哪一种失败原因；为什么冻结或训练这些模块；成功结果说明什么；失败结果将如何改变下一步判断。
7. 普通概念优先使用中文。模型名、函数名、配置字段和仓库标识可以保留英文；其余术语首次出现时给出中文含义，后续统一使用中文。不得连续堆叠未经解释的英文词组。
8. 发送前必须进行一次可读性验收。若首段需要读者先理解仓库内部代号才能看懂、删除代码字段和英文标签后正文失去主要含义、连续三个以上条目只是短语或命令、公式/路径/指标/实验编号淹没主要判断、没有回答为什么/结果说明什么/接下来怎么做，或回答像 executor contract、控制台记录、审查清单，就必须重写。

## Default Structure

最终分析正文默认使用以下顺序：

1. 总体判断；
2. 为什么现在需要处理这个问题；
3. 现有实验和代码已经说明了什么；
4. 当前目标是否达成；
5. 真正的瓶颈是什么；
6. 下一步最小且可证伪的行动；
7. 技术细节或训练合同，必要时放在最后。

## Heading Rule

不得把仓库内部科学命名直接当回答标题。标题必须先写自然判断，例如：

- 下一轮应优先修复训练目标与最终预测结果不一致的问题；
- 先用最小实验确认梯度是否真正作用于最终输出；
- 只有修复输出机制仍无效，才说明中间表征本身不足。

内部代号可以放在段末括号中，供仓库检索；不得要求读者先学习一套命名系统。

## Controller Report Rule

`controller_report.md` 必须以一个自然中文段落开头。该段先回答：当前任务真正完成了什么或卡在哪里，为什么会这样，控制器现在建议做什么，暂时不允许做什么。随后再给证据摘要、路径、命令、指标和机器字段。不得让 `controller_verification_decision`、`operational_completion_status`、实验代号或状态 token 成为读者看到的第一个结论。

## Acceptance Check

最终输出通过前，作者必须确认：

- 第一段不依赖内部代号也能读懂；
- 每个内部标签前都有自然中文解释；
- 机制段包含“目的、缺口、信息流或梯度变化、最小验证实验”；
- 公式有前后解释；
- 训练阶段不是裸 checklist；
- 技术字段、路径、命令和状态名放在判断之后，而不是替代判断；
- 最后一版读起来像科研负责人对团队的分析，而不是控制台记录或任务合同。
