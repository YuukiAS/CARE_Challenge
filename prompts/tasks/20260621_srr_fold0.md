## 实验设计

使用同一 fold0 split、seed、preprocessing、patch policy、iteration/runtime budget 和 evaluator。优先让两个 variant 并行训练，以节省时间。

### Variant A：`conditional_dualhead_control`

目的：隔离最基本的数据机制收益，不使用 selective retrieval。

必须包含：

- modality-specific input handling 或 architecture contract 指定的 deterministic availability-aware late fusion；
- separate scar/edema heads；
- scar 主要由 LGE evidence 驱动；
- edema dense loss 只在 T2-present cases 可信启用；
- anatomy auxiliary head/prior仅按 contract 的最小形式；
- 与 Variant B 相同的数据采样、modality dropout 和训练预算；
- 不使用 shared/private retrieval gate 和 SIP-inspired regularizer。

### Variant B：`srr_minimal`

目的：检验 Result4 的核心 selective representation retrieval 是否优于 conditional control。

必须严格按照 architecture contract，包括：

- modality-specific representation；
- shared/private representer dictionary；
- availability + feature-conditioned retrieval gate；
- scar/edema/anatomy task-specific retrieval或decoder；
- T2-masked edema supervision；
- contract 规定的 sparsity、integrativeness/SIP-inspired 和 anti-collapse regularization；
- identical baseline-preserving fallback；
- optional alignment 暂不启用，除非 contract 明确将其列为首轮必需。

## 训练资源策略

- 每个 job `--time` 不超过 `08:00:00`。
- 不要只训练几个 epoch。应在 8 小时预算内充分使用 GPU，优先设置 4-6 小时有效训练预算，加 validation/导出余量。
- 可以使用 2D 或轻量 3D，但必须由 architecture contract 和 Dataset501 spacing/patch审计决定；不能仅为省时选择明显不合适的维度。
- 两个 variant 应使用相同 max-runtime、validation cadence、best-checkpoint rule。
- 允许在正式 jobs 前运行 one-batch/tiny-overfit gate，但该 gate 通过后必须继续 fold0，不要停在 smoke。
- 如果资源允许，两个 variant 分别提交独立 Slurm job；不得让并行 job 写入同一 cache/checkpoint/prediction 目录。

## 数据采样与监督

- fold0 train/val 使用官方 protocol split。
- 所有 220 cases 可参与 scar/anatomy 学习，按 contract 使用真实可用模态。
- edema dense supervision 只来自 T2-present complete cases。
- complete cases 需要适度 oversampling，避免 T2 expert starvation；采样比例和实际 batch counts必须记录。
- modality dropout 只能按 contract 生成医学和监督上合法的观测组合；不得把 dropped T2 后的原 edema label继续当成可见 T2 dense evidence。
- 报告每个 epoch 或固定间隔的 modality-pattern batch distribution、edema-supervised batch fraction 和 expert usage。

## 决策门

`results/20260621_srr_fold0/decision.md` 必须给出以下之一：

- `GO_ABLATION`
- `REVISE_ROUTING`
- `KEEP_CONDITIONAL_ONLY`
- `STOP_SRR`
- `STOP_PIPELINE_BUG`

进入 `GO_ABLATION` 的最低条件：

- Variant B predictions 非空，label/cache/export 正确；
- 相比 Variant A，T2-present/GT-positive edema Dice 或 HD95 有稳定正信号；
- scar all-case 不出现实质退化；
- LGE-only scar 不崩溃；
- HD/HD95 和 remote components 不出现不可解释恶化；
- gain 不能主要来自 empty-GT cases；
- gate 不 collapse 到单一 expert，且不存在大面积 expert starvation。

若 Variant A 明显优于现有 nnU-Net，但 Variant B 无增益，则选择 `KEEP_CONDITIONAL_ONLY`，不要为了故事强留 retrieval。
