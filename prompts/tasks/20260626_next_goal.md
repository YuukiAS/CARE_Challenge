# Goal 20260626: Dictionary Construction Sprint

## 总目标

这不是一次 minor fix。目标是在 12-24 小时级别的连续推进中，系统构建和比较多种 Result4/SRR dictionary 设计，尽最大努力把 MyoPS 的 shared/private representation dictionary 从“相对有效但分数低”推进到“可解释、可选择、可继续扩展”的阶段。MyoPS 是绝对主线；CineMyoPS 同步推进 safe-subset temporal retrieval，但不得阻塞 MyoPS。

本 goal 明确授权 Codex 在每个单 job `<=08:00:00` 的前提下，用多个 task、多个 variants 和多个并行 Slurm jobs 形成较长时间的推进。不要因为几个样本、几个 epoch、一个 variant 失败或一个 metric caveat 就草率停止。必须完成同一 task 内其他 variants，失败也要结合数据机制和 dictionary 本质解释。

## 执行顺序

### Phase 0：安全检查与并行准备

记录 branch、HEAD、git status、untracked files、当前 SRR selected route、Cine safe/mismatch split。确认不会覆盖 `results/20260621_*` 或 `results/20260625_*`。若并行 worktree/session 可用，应为 MyoPS dictionary bank、Cine temporal、research summary 建立清晰隔离；否则按优先级串行。

### Phase 1：bounded dictionary research 与 dictionary bank 并行

`20260626_dict_research` 可以与 `20260626_dict_bank` 并行。research 的结果若及时完成，应反馈给 dictionary bank；若 dictionary bank 已经启动，不得阻塞。research 任务允许联网，但只查 dictionary、routing、shared/private representation、MoE anti-collapse、missing-modality dense segmentation 相关内容，不查泛化大模型。

`20260626_dict_bank` 是本轮核心。必须至少尝试 4 条 dictionary 路线，最好 5-6 条。每条 formal job 尽量使用 6-7 小时有效训练预算，单 job 不超过 8 小时。允许最多 5 个并行 GPU jobs。某个 variant 失败不能阻止其他 variants；只有 label/fold/evaluator/cache/no-T2 supervision 出错才硬停。

### Phase 2：lesion compactness package

只有 `20260626_dict_bank` 产生 `SELECT_DICTIONARY_VARIANT` 或 `SELECT_BASE_SRR`，才进入 `20260626_lesion_compact`。该任务不是单独修一个 loss，而是在 selected dictionary route 上系统处理病灶定位、远端假阳性、component burden、scar LGE fallback 和 T2-positive edema localization。至少运行 3 条 formal variants，资源允许则运行 4-5 条。每条 job 仍尽量使用 6-7 小时有效训练预算。

如果 dictionary bank 的选择是 `REVISE_DICTIONARY_AND_REPEAT`，则不要强行进入 compactness；应在 final_status 中给出下一张 dictionary-repeat task 建议。

### Phase 3：Cine temporal 次线

`20260626_cine_temporal` 应尽早启动，但不阻塞 MyoPS。它应在 59 个 safe cases 上做 reference control 与 temporal/anatomy retrieval preflight。若 temporal preflight 比 reference control 没有正信号，也要解释失败是 label reference限制、nonreference feature未配准、key-frame选择、retrieval collapse还是scar head缺失。5 个 mismatch cases 仍在 repair queue，不阻塞 safe subset。

### Phase 4：汇总和下一步门

汇总 MyoPS dictionary bank、lesion compactness 和 Cine temporal 结果。不要把任何单一 fold0 正信号说成可提交。最终判断应回答：dictionary 是否继续作为主线、哪个 dictionary 结构最值得、是否还需要继续修 localization、是否允许下一轮 fold expansion、Cine 是否继续 temporal route。
