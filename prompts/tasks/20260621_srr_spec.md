## 必须冻结的 architecture contract

将最终规格写入：

- `results/20260621_srr_spec/architecture_contract.md`
- `results/20260621_srr_spec/architecture_contract.yaml`

contract 至少明确以下事项。

### 1. 方法主张

用一句话说明 Result4 正式方法如何同时处理：

- blockwise missing modalities；
- modality/center heterogeneity；
- scar 与 edema 的不同证据来源；
- shared/private representation；
- anatomy prior；
- optional alignment。

### 2. 最小可训练版本

按 Result4 选择并固定：

- LGE、C0、T2 modality-specific stem/encoder；
- shared/private representer dictionary 的位置和数量；
- dense feature retrieval 的层级；
- retrieval gate 输入：availability vector、feature summary 或两者；
- missing modality mask 如何严格关闭无效表示；
- scar-specific、edema-specific、anatomy-specific decoder/head；
- T2-conditioned edema loss；
- scar 的 LGE-preserving fallback；
- modality dropout 规则；
- anatomy soft prior；
- Result4 推荐的 SIP-inspired/integrativeness regularizer 的可训练近似；
- gate collapse、expert starvation 和 over-sharing 防护；
- inference 不依赖 center ID 的保证。

如果 Result4 给出多个候选，首轮必须选一个最小版本。optional alignment、复杂 interaction dictionary、temporal unification 等不进入首轮实现，除非 Result4 明确把它列为不可删除的核心。

### 3. 数据与监督矩阵

对每种训练模态组合明确：

- 哪些 encoder/representer 有效；
- 哪些 head 接收 dense supervision；
- edema loss 权重；
- scar/anatomy supervision；
- modality dropout 是否允许；
- 不允许的 synthetic combination。

### 4. 总损失

写出明确公式和默认权重范围，至少包括：

- anatomy segmentation loss；
- scar loss；
- T2-masked edema loss；
- retrieval sparsity/entropy；
- SIP-inspired sharing/integrativeness；
- load balancing或coverage防止 expert collapse；
- anatomy containment/soft prior；
- optional consistency项。

### 5. Baseline-preserving fallback

模型必须支持以下故障回退：

- scar route 在只有 LGE 时仍可正常工作；
- T2 不存在时 edema head 不接受硬负监督；
- retrieval gate 失效时可退化为确定性 availability-aware late fusion；
- 每个 variant 使用独立 checkpoint、prediction、metric、cache 目录。
